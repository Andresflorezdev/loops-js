# Taller de Loops en JavaScript

Taller práctico de algoritmos utilizando diferentes estructuras de bucles (`for`, `while`, `do...while`, `break/continue` y bucles anidados) simulando operaciones estilo Nequi.

---

## Requisitos Previos

- [Node.js](https://nodejs.org/) instalado en tu sistema.
- Gestor de paquetes `pnpm` (o `npm`).

---

## Instalación

Para instalar las dependencias necesarias (como `prompt-sync` para la entrada de datos por consola), ejecuta:

```bash
pnpm install
```

*(Si no usas `pnpm`, puedes usar `npm install`)*.

---

## Ejecución de Ejercicios

Puedes ejecutar cualquiera de los ejercicios con Node.js:

```bash
node ejercicio1.js
node ejercicio2.js
node ejercicio3.js
node ejercicio4.js
node ejercicio5.js
```

---

## Contenido del Taller

- **Ejercicio 1:** Bucle `for` — Balance total y conteo de retiros.
- **Ejercicio 2:** Bucle `while` — Validación de PIN de seguridad.
- **Ejercicio 3:** Bucle `do...while` — Menú interactivo de opciones.
- **Ejercicio 4:** Control de flujo — Filtrado y búsqueda con `continue` y `break`.
- **Ejercicio 5:** Bucles anidados (`for` dentro de `for`) — Balance por usuario.
